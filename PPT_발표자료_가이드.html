Slide 1~2 · 권장 55초
"하루의 90%를 실내에서 보내는 현대인, 창문이 없거나 열 수 없는 공간의 심리적 고립과 생체리듬 붕괴"

1인 가구 · 반지하 · 오피스텔 거주자 창문이 아예 없거나 바로 앞이 벽(뷰 차단)이어서 낮/밤 구분 불가 및 수면장애·우울감 호소 고정된 액자나 TV 영상은 입체 채광(햇빛)이 없고 매번 리모컨으로 영상을 찾아 틀어야 함

미세먼지 · 황사 · 폭염/한파 속 실내 체류자 실제 창문이 있어도 대기오염·소음 때문에 하루 종일 블라인드를 닫고 생활 수백만 원대 고가 천장형 인공채광기(CoeLux 하드웨어)는 시공이 필요해 일반 가정 도입 불가

4️⃣ AI 활용 방식 (입력 ➔ AI 처리 ➔ 사용자 가치 & AI 유무 비교)

Slide 7~8 · 권장 50초 · ★ 대회 주제 직결 핵심 항목
"단순 명령어 매칭을 넘어, 사용자의 모호한 말과 창문 속 이미지를 멀티모달 AI가 이해하고 공감각(시각·채광·청각)으로 재구성합니다"

① [입력(Input) ➔ AI 처리(AI Process) ➔ 사용자 가치(User Value)] 5대 파이프라인

구분 📥 입력 (Input) 🧠 AI 처리 (AI Process — 모델 & 알고리즘) 💎 사용자 가치 (User Value)
1. 음성 의도 & 프롬프트 추론 한국어 자유 발화
(예: "윈도, 비 오는 도쿄 밤거리 보여줘")		 Google Speech STT + Gemini 3 Flash
호출어 분리 ➔ 의도 분류 ➔ 영문 Stable Diffusion 프롬프트 및 네거티브 프롬프트 자동 엔지니어링		 복잡한 프롬프트 작성법이나 키보드 조작 없이 일상 대화만으로 원하는 창문 풍경 즉시 획득
2. 온디바이스 생성 & 웹 비전 큐레이션 변환된 프롬프트 또는 검색 키워드 ComfyUI (SD 1.5) / OpenCV 비전 검수기
16:9 창문 비율 이미지 합성 또는 웹 후보 이미지의 해상도·선명도(Laplacian)·구도 스코어링		 깨지거나 구도가 어색한 사진 없이 실제 창문 너머로 보는 듯한 고화질 파노라마 뷰 감상
3. 현재 사진 기준 시간대 타임랩스 현재 창문에 띄워진 이미지 1장 Gemini 3 API (`gemini-3-flash-preview` / Image Edit) + Relighting Engine
원본 사진의 시간대(아침/노을/저녁) 판별 ➔ 동일 구도를 유지한 채 다음 시간대 이미지 2장 생성		 정지된 사진 1장만 있어도 내 창문 풍경에 아침·노을·밤이 찾아오는 생생한 시간의 흐름 경험
4. 가상 코에룩스 광원 좌표 추론 활성화된 창문 배경 이미지 AI 광원 분석기 (Luminance & Sky Segmentation)
이미지 상단 하늘 영역의 최대 휘도 중심점(X%, Y%) 및 색온도(K) 추정 ➔ 대기 산란 글로우 합성		 수백만 원대 하드웨어 시공 없이도 사진 속 해·달 위치에서 실제로 햇살이 쏟아지는 입체 개방감 체감
5. 배경 맞춤 사운드 & 공기질 추론 배경 이미지 + 실내 센서 수치(PM/CO₂/VOC) Gemini Vision 멀티모달 분석 + 하이브리드 상태 판단
풍경 분위기(파도 세기, 도시/자연, 낮/밤)에 맞는 오디오 트랙 매칭 & 공기질 행동 요령 생성		 풍경이 바뀔 때마다 소리와 건강 브리핑까지 알아서 맞춰주는 완전자율 스마트 공간 완성

② AI가 없을 때(Before AI) vs WINDO AI 도입 후(With WINDO AI) 결정적 차이

비교 항목 ❌ AI가 없을 때 (기존 디지털 액자 / 유튜브 풍경 재생) ✅ WINDO AI 적용 후 (본 서비스)
풍경 확보 방식 사용자가 직접 검색어를 입력해 영상을 찾고 광고를 넘기며 수동 재생 "~ 만들어줘 / 찾아줘" 말 한마디로 AI가 프롬프트 번역·생성·화질 검수까지 자동 수행
시간대 변화 (타임랩스) 내가 원하는 사진의 다른 시간대(노을·밤)가 없으면 시간 변화 표현 자체가 불가능 현재 사진 1장만 있으면 AI가 시간대를 분석해 노을·저녁·아침 이미지를 생성하여 순환 재생
채광(조명) 연동 배경 사진 속 태양 위치와 무관하게 일정한 모니터 불빛만 출력 (이질감 발생) 사진 속 해/달의 실제 좌표(X, Y)와 색온도를 AI가 추적해 가상 코에룩스 입체 채광 자동 동기화
사운드 연동 배경을 바꿀 때마다 사용자가 어울리는 ASMR/백색소음을 따로 찾아 틀어야 함 Gemini Vision이 사진 속 풍경(거친 바다 vs 잔잔한 바다 등)을 읽고 최적의 환경음을 자동 크로스페이드
장애 대응 안정성 네트워크나 외부 API 오류 시 서비스 멈춤 2단계 하이브리드 폴백(Gemini API ➔ 로컬 CV/휴리스틱 엔진)으로 무중단 동작 보장
